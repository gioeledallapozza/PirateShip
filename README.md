# 🏴‍☠️ Pirate Ship — Interactive Three.js Portfolio

An immersive Three.js / WebGL portfolio site built around a fully modeled pirate ship. Instead of a static resume page, the ship acts as a navigable scene: clickable hotspots on the vessel open contextual "Ship's Log" entries about my background, technical approach, and interests.

This was my first real project in the Three.js / WebGL space — the foundational learning ground that led directly into building production-grade tools like my Porsche 911 GT3 RS Configurator.

## 🌊 The Core Challenge: Custom Water Shaders
The biggest technical hurdle of this project wasn't the UI or the models, but building a custom, performant ocean from scratch in vanilla Three.js without relying on high-level R3F abstractions. 

I wrote custom GLSL shaders to handle the water physics and aesthetics:
* **Vertex Shader (Gerstner Waves):** Implements a loop of multiple Gerstner waves to displace vertices, manually calculating tangents and bitangents to ensure accurate normal mapping on the deformed surface.
* **Fragment Shader:** Handles a complex PBR-lite material including subsurface scattering (SSS) for light passing through wave peaks, Fresnel reflections, dynamic sea foam generated by wave steepness thresholds, and custom atmospheric fog blending.

## ✨ Features
* **Interactive hotspots:** Clickable points anchored to specific meshes on the 3D model (rudder, sails, anchor, jibboom), each opening a themed modal.
* **Camera choreography:** GSAP-driven camera transitions fly to a tailored position/target for each hotspot instead of a hard cut.
* **Occlusion-aware hotpoints:** Hotpoints raycast against the ship mesh every few frames and hide themselves when occluded by the geometry, instead of floating through the hull.
* **Dual-mode UI:** A standard scrollable landing/about section for fast scanning, plus a fully immersive 3D mode with drag-to-explore / scroll-to-zoom controls (with touch-friendly pinch-to-zoom on mobile).

## 🛠️ Tech Stack
* **Core:** Vanilla JavaScript + Vite
* **3D Engine:** Three.js, Custom GLSL Shaders
* **Animation:** GSAP
* **Styling:** Custom CSS (no framework)

Built while exploring Three.js and WebGL for the first time. The focus was on getting comfortable with real-time 3D fundamentals—scene graphs, camera math, custom shader pipelines, and maintaining 60 FPS across devices—before moving on to production-oriented React Three Fiber architectures.
